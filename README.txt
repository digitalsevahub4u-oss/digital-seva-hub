DIGITAL SEVA HUB — WEBSITE FILES

Files:
- index.html: website content
- style.css: responsive styling
- script.js: mobile menu and enquiry-template button
- images/: uploaded sample service images

PREVIEW:
Double-click index.html to open it in a browser.

PUBLISH FREE WITH GITHUB PAGES:
1. Sign in to https://github.com
2. Click + (top right) > New repository.
3. Repository name: digital-seva-hub
4. Choose Public, then Create repository.
5. Click Add file > Upload files.
6. Upload index.html, style.css, script.js and the images folder with all its images.
7. Click Commit changes.
8. Open Settings > Pages.
9. Under Build and deployment, choose Deploy from a branch.
10. Choose branch main and folder /(root), then Save.
11. Wait a few minutes. Your website URL will look like:
    https://YOUR-GITHUB-USERNAME.github.io/digital-seva-hub/

IMPORTANT CUSTOMISATIONS:
- The email enquiry button currently uses a placeholder address:
  hello@digitalsevahub.example
  Replace it in index.html with your real business email before publishing.
- No phone number or WhatsApp number was provided, so no unverified contact details have been added.
- GitHub Pages can host this static website free. A custom .com domain is optional and usually costs money.
